# Оконопад

Снег на окнах твоего Mac. Снежинки оседают на верхних кромках окон, а сугробы можно стряхнуть курсором или резким движением окна.

## Как запустить

Нужен Mac с Apple Silicon и macOS 14 или новее. Для сборки нужны Git и Swift 5.9 или новее. Они входят в Xcode Command Line Tools. Если `swift --version` не работает, выполни `xcode-select --install` и дождись завершения установки.

В Терминале выполни:

```bash
git clone https://github.com/Tim-arc/Oknopad.git
cd Oknopad
bash scripts/bundle.sh
open .build/SnowDesktop.app
```

Скрипт собирает релизную версию и кладёт приложение в `.build/SnowDesktop.app`. После запуска ищи снежинку в строке меню macOS. Эффект отображается на основном мониторе, а клики проходят сквозь него.

## Управление

- **Flurries / Snowfall / Blizzard** — выбрать интенсивность. Настройка сохраняется между запусками.
- **Pause Snow / Resume Snow** — скрыть или вернуть эффект.
- **Clear Snowdrifts** — убрать накопившийся снег.
- **Quit SnowDesktop** — завершить приложение.

Чтобы стряхнуть снег, быстро проведи курсором вдоль заснеженной кромки или резко сдвинь окно за заголовок. Осыпавшийся снег может осесть на окне ниже.

## Проверка сборки

После сборки выполни в графическом сеансе macOS:

```bash
.build/SnowDesktop.app/Contents/MacOS/SnowDesktop --smoke-test
```

Команда проверяет запуск Metal, паузу, возобновление, расчёт видимых участков оконных кромок и физику стряхивания. В конце выводится p99 времени подготовки кадра на CPU и выполнения команды Metal на GPU.
